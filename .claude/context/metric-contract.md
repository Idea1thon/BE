# 입지 근거 지표 계약

현재 공개 데이터만으로 신규 점포 성공확률을 신뢰성 있게 추정할 수 없으므로, 서로 다른 의미의 근거를 하나의 정답처럼 섞지 않는다.

지역 단위 특성값(업종·조건 무관 서술)은 `artifacts/10-analysis/regional-characteristics-profile.md`에 feature id로 정의한다. 아래 근거 차원은 그 feature들을 사용자 업종·조건과 결합해 해석하는 축이다.

## 근거 차원

| 차원 | 기본 지표 | 해석 |
| --- | --- | --- |
| 현재 수요 | 업종 매출 수준, 매출 건수, 유동인구, 시간·요일 적합성 | 지금 해당 고객이 존재하는가 |
| 경쟁·시장수용 | 동종 점포수, 점포 밀도, 점포당 매출, 프랜차이즈 비율 | 경쟁이 강한가, 시장 규모가 함께 큰가 |
| 진입 건전성 | 개업률, 폐업률, 순개업, 점포 증감, LL/LH/HL/HH | 신규 진입 환경이 과열·축소·고착인지 |
| 비용 부담 | 임대료 권역 분위, 공실률 권역 분위 | 비용과 공급 위험이 어느 정도인가 |
| 수요 구성 | 상주·직장·유동인구 구성, 연령·성별·시간대 | 사용자의 고객·영업조건과 맞는가 |
| 미래 신호 | 최근 유동·매출·점포의 실제 갱신 시계열, 공식 개발 사건 | 방향성이 있는가 |
| 데이터 신뢰도 | 최신성, 공간 매칭, 누락률, 표본·업종 커버리지 | 추천 근거를 얼마나 믿을 수 있는가 |

## 정규화

- 사용자가 선택한 시군구 범위 안의 분위수와 서울 전체 분위수를 함께 계산한다.
- 총량은 면적 또는 인구 규모 효과를 따로 표시한다.
- 업종별 값은 같은 업종 안에서만 비교한다.
- 지역별 표본이 너무 적으면 순위를 만들지 않고 `근거 부족`으로 표시한다.

## 후보 분류

- `추천`: 필수 조건을 충족하고 수요·진입 근거가 있으며 치명적 반대 근거가 없음
- `조건부 검토`: 장점은 있으나 비용, 경쟁, 최신성, 누락 중 하나가 큼
- `주의`: 필수 조건 불충족 또는 폐업·비용·데이터 품질 위험이 큼

동일 상태 안에서 화면 순서를 정해야 하면 `필수조건 충족 → 데이터 신뢰도 → 수요 근거 수 → 진입 건전성 → 반대 근거 심각도` 순으로 비교한다.

필요하면 `fit_index_v1`을 내부 보조값으로 계산할 수 있지만, 반드시 `score_is_predictive=false`를 함께 반환하고 공개된 산식·버전·누락 처리 규칙을 제공한다.

## 금지된 해석

- F1이 높으므로 신규 점포 성공을 잘 예측한다.
- 매출이 높은 지역이므로 신규 점포도 성공한다.
- 동종 점포가 많다는 사실만으로 수요 또는 경쟁을 단정한다.
- 공실률 권역값을 특정 주소의 현재 공실로 표현한다.
- 상주·직장·아파트의 반복값을 분기별 성장으로 해석한다.
- SNS 합성 JSON을 실제 관측 데이터로 표현한다.

## 학습모델 재검토 조건
