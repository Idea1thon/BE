## 상태 규칙

- `current`: 최신 입력 반영
- `stale`: 앞 단계 변경으로 재실행 필요
- `needs-review`: QA 또는 사람 확인 필요
- `archived`: 이전 실행 보관

승인 상태는 `사용 가능`, `사람 승인 필요`, `미검증 영역 있음`, `해당 없음`만 사용한다.
