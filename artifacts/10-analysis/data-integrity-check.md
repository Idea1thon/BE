## High

### H1. 2025↔2026 폴더 분기 중복 (점포·추정매출)

`2025년/` 파일과 `2026년/` 파일이 **20251~20254 네 분기를 양쪽 다 수록**한다. 연도 폴더를 그대로 concat하면:

| 병합 대상 | 정상 분기 행수 | 20251~20254 행수 | 중복 키 |
| --- | --- | --- | --- |
| 점포-상권 (2021~2026 전체) | 약 160,000/분기 | 약 320,000/분기 | 1,255,768 키 / 2,888,362 행 |
| 점포-행정동 | 약 35,200/분기 | 약 70,600/분기 | 141,218 키 / 282,436 행 |
| 추정매출-상권 | 약 22,000/분기 | 약 79,700/분기 | 85,732 키 / 214,459 행 |
| 추정매출-행정동 | 약 17,200/분기 | 약 33,500/분기 | 67,113 키 / 134,226 행 |

- 개별 파일 안에는 중복이 없다(`점포/2026년/(점포-상권).csv` 380,747행, 중복 키 0). 중복은 오직 파일 간에서 발생.
- 2026 파일은 20251~20261, 2025 폴더 파일은 20251~20254, 2021~2024 폴더 파일은 각 해당 연도 4분기.
- **권장 병합 규칙**: 분기를 파일에 1:1로 배정한다. `2021년~2025년` 폴더 = ≤20254 담당, `2026년/*.csv` = 20261만 담당. (2026 파일이 다시 쓴 2025 값은 버린다.)
- 배후지는 예외: 추정매출 배후지는 `2025년` 폴더에 정상 배후지 파일이 없어(H4 참조) 2026 파일이 20251~20261을 단독 커버 → 배후지 병합 중복은 0.

### H2. 점포 컬럼 스키마 2세대 (2021–2025 vs 2026)

| 스키마 | 파일 | 점포수 계열 컬럼 |
| --- | --- | --- |
| 구(2021~2025) | 상권·배후지 10개, 행정동 5개 | `점포_수`, `유사_업종_점포_수`, `프랜차이즈_점포_수` |
| 신(2026) | 상권·배후지 2개, 행정동 1개 | `전체_점포_수`, `일반_점포_수`, `프랜차이즈_점포_수` |

- 2026에는 `유사_업종_점포_수`가 **없고**, `일반_점포_수`가 새로 생겼다.
- 값 검증: 2026 `전체_점포_수 = 일반_점포_수 + 프랜차이즈_점포_수` (378,031행 일치, 불일치 0, 전체0 2,716행).
- **매핑 규칙**: 구 `점포_수` ↔ 신 `전체_점포_수`로 통일. `유사_업종_점포_수`를 피처로 쓰면 20261 분기는 결측 처리. `일반_점포_수`는 `전체_점포_수 - 프랜차이즈_점포_수`로 구 분기에도 역산 가능.
- 이름 기반(header) 결합 시 그대로 깨진다. 위치 기반 로더 + 명시적 rename 필요.

### H4. 추정매출 2025 배후지 파일: grain 라벨 오류 + 부분 영문

`추정매출/2025/서울시 상권분석서비스(추정매출-상권배후지)_2025년.csv` 한 파일만:

- 공간 코드 컬럼이 `trdar_cd`(정규화 시 `상권_코드`)로 라벨링됨. 다른 배후지 파일은 `상권배후지_코드`.

- **처리**: grain은 컬럼명이 아니라 (a) 파일 경로/이름의 `배후지` 여부와 (b) 코드값이 영역-상권/영역-배후지 중 어디에 속하는지로 판정. 이 파일은 배후지로 강제 배정하고 영문 컬럼 46개를 rename.

## Medium

### M1. 추정매출 "매출_건수" 블록 컬럼명 손상

모든 한글 추정매출 파일(스키마 3종)에서 시간대 **건수** 컬럼명이 깨져 있다:
`시간대_00~06_매출_건수` → `시간대_건수~06_매출_건수` (06/11/14/17/21/24 전부 `건수~NN` 꼴). 금액 블록(`시간대_00~06_매출_금액`)은 정상.
- 원인: 원본 로컬라이즈 시 `00`→`건수` 치환 사고로 추정. 영문 파일은 `tmzon_00_06_selng_co`로 정상.
- 위치 기반 접근이면 무해. 이름으로 시간대 컬럼을 집으면 건수 6개가 안 잡힌다. 로더에서 rename 목록에 포함.

### M2. 추정매출 상권 커버리지 1,577 / 1,650

영역-상권 1,650개 중 추정매출(2026 기준)은 1,577개만 존재. 73개 상권은 매출 추정치 없음(표본 부족 상권으로 추정).
- 결합은 영역/점포 기준 left join, 매출 없는 상권은 `null` + `missing_reason="추정매출_미제공"` 유지. **0으로 대체 금지**(계약 준수).
- 후보 근거에서 "현재 수요" 차원이 비면 `조건부 검토` 이하로 내리고 누락을 표시.

### M3. 인코딩 혼재

- CP949: 점포·추정매출·인구·상권변화·영역 전 파일 (57개)
- UTF-8-BOM: `data/매장용빌딩 임대료,공실률 및 수익률 통계 데이터.csv`
- UTF-8: `추정매출/2024/서울시 상권분석서비스(추정매출-상권배후지)_2024년.csv`
- 로더는 파일별 인코딩 감지(BOM → CP949 시도 → UTF-8 폴백) 필수. 단일 인코딩 가정 금지.

### M4. 임대료 파일 구조 — 권역 grain, wide 포맷, 시계열 1분기 뒤처짐

`매장용빌딩 임대료,공실률 및 수익률 통계 데이터.csv`:
- **2행 헤더**(row0 지표군: 임대료(천원/㎡)/공실률(%)/수익률, row1 세부: 소계/투자수익률/소득수익률/자본수익률), 75행, 102열.
- 분기가 컬럼으로 pivot: `2021 1/4` ~ `2025 4/4`, 분기당 5열 = **20개 분기, 2021Q1~2025Q4**. 20261 없음 → 최신 시계열(상권·점포·매출 20261) 대비 1분기 뒤처짐.
- 공간 grain: `지역별(1)`/`지역별(2)` 권역(서울-소계, 도심/강남/여의도마포 등 대분류). **상권·배후지·행정동 폴리곤과 직접 매칭 불가.**
- 계약대로 `conditional`, 권역 비용·공급 위험 설명용. `투자수익률/소득수익률/자본수익률` 3열은 운영 allowlist 제외 유지.

## 결합 파이프라인이 지켜야 할 규칙 (이 검사에서 새로 확정)

1. **분기-파일 1:1 배정.** 점포·추정매출은 `2021년~2025년` 폴더가 ≤20254, `2026년/*.csv`가 20261 담당. 2026 파일의 20251~20254 행은 로드 시 제외.
2. **로드 순서: 위치 기반 읽기 → 컬럼 rename(ENG2KOR + M1 건수블록 + H2 점포수 매핑) → grain 판정(경로·코드값 기반) → 표준 키 부여.**
3. grain 판정은 컬럼명 신뢰 금지. 경로의 `배후지`/`행정동` 문자열 + 코드값이 영역-상권/영역-배후지/영역-행정동 중 어디 속하는지로 결정(H4).
4. 파일별 인코딩 감지(M3).
5. 커버리지 부족은 `null` + `missing_reason` 유지, 0 대체 금지(M2, L1).
6. 임대료는 별도 로더(2행 헤더 언피벗, 권역 grain). 상권 후보에 직접 붙이지 말고 권역→후보 매핑 테이블 경유(M4).
7. 상권변화지표는 배후지 요청 시 상권값으로 fallback하고 grain 표시(배후지 버전 없음).
