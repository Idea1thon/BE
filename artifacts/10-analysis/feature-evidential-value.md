# FC 피처 설명력 검증 (2026-09-02)

하네스 내부 검증 산출물. 지역 특성 프로파일(FC feature 24개)이 "좋은 입지"를 실제로 판별하는지, FC끼리 중복되는지, 7 근거 차원이 분리되는지 실측.

- 스크립트: `scripts/build_feature_outcome_panel.py` · `analyze_feature_evidential_value.py` · `plot_feature_evidential_value.py`
- 산출: `output/feature_validation/*.csv` · `output/figures/feature_validation/*.png`
- 상위 계약: `.claude/context/metric-contract.md`(7 차원), `regional-characteristics-profile.md`(FC 정의), `artifacts/adr/ADR-001-evidence-first-ranking.md`

## 1. 방법과 한계

- **grain**: 상권 × 업종 (10 외식업, 20261) + 상권 단위(전 외식 pooled).
- **outcome (프록시)** — 두 개의 별개 universe:
  - **인허가 행정**: `churn_ratio` = 2022~2025 폐업 수 / 개업 수 (`data/인허가/음식점_상권분기_패널.csv`, 완전분기). `surv_1y` = 코호트(2021~2024 인허가) +4Q 생존율.
  - **점포분석서비스**: `close_r_4q` = 4분기 평균 폐업률, `net_open_4q`, `delta_store` = 점포수 YoY.
  - 두 universe는 `data-integrity-check.md`에서 **분기 폐업률 r≈0.11** — 서로 다른 것을 잰다.
- **분석**: Spearman(rank 후 Pearson, scipy 없이). pooled 상관은 **업종 내 분위끼리** 비교(치킨·커피 프랜차이즈 등 업종 기저율 제거). 편상관 = 통제(점포밀도·매출) 후 잔차 Spearman. **적합 모델(로지스틱 등) 만들지 않음** — 스코어링 엔진 오인 방지.
- **표본**: churn ρ n=2,108(opens≥5) · 점포 outcome n=5,430(점포≥5) · 상권 pooled n=556(opens≥20).
- **결정적 한계**: **신규 점포 매출·손익·브랜드 outcome 없음** (metric-contract 학습모델 재검토 조건 미충족). 이 검증은 **"FC가 폐업/생존·성장과 통계적으로 연관되는가"** 까지만 답한다. "좋은 입지 = 성공"은 여전히 검증 불가.
- `surv_1y` median ≈ 90%(포화) → 보조. FC-41·42·52·53은 자치구/업종 상수라 상권 내 판별력 없음(pooled·모멘텀만).

## 9. 파이프라인 함의

1. **학습형 결합 스코어(`fit_index_v1` 가중 모델)를 만들지 않는다.** 결합할 신호가 없다. `fit_index_v1`은 만들더라도 **공개 산식의 표시 정렬 휴리스틱**에 그쳐야 하고, "예측"으로 노출 금지 (ADR-001·metric-contract 재확인).
2. **파이프라인의 가치는 "증거 제시기"** — 지역 특성을 보여주고, 검증된 2개 범주 신호(FC-10 등급·FC-11 라벨)를 배경 리스크로, 나머지는 서술 근거로. 추천/조건부/주의 등급은 **하드 조건 + 근거 차원 유무 + 반대 근거**로만 (현행 spec §3~5 그대로), 피처 가중합 금지.
3. **FC 우선순위** (프로파일 status·판정 반영):
   - **유지(범주 신호)**: FC-10(등급), FC-11(라벨) — §8
   - **약한 배경 신호로만**: FC-07(대중교통, bus_n이 그나마), FC-08(배후주거), FC-31(매출, "성공 아님" 주석 강화)
   - **서술만 — 존속 근거 승격 불가**: FC-04(직장), FC-03(상주). 2026-09-03 재검증(`site-typology.md` 2단계) — 상권 유형(신도시형/골목형)으로 층화해도 상주·직장인구 수준 ↔ 폐업/생존 |ρ|<0.2, 유형이 관계를 조건화하지 않음. "인구 많음 = 수요 크지만 진입·퇴출도 활발" 패턴. `context_notes` 전용, 파이프라인 미연결 유지
   - **모멘텀 신호(품질 아님, 주의 표기)**: FC-32(프랜차이즈 = 체인 확장), FC-12(폐업추세)
   - **신호 없음 — 서술만, 순위·판정 근거 금지**: FC-01·02·05·06a·06b·30·40·41·51·53
   - **미신뢰(데이터 미비)**: FC-20(R-ONE 상권 매핑 후 재검증), FC-42(업종 상수), FC-52(자치구 상수)
   - **중복 축소 검토**: FC-06a/06b, FC-07 역수/역거리
4. **차원**: 7개 차원 구조는 유지(개념적 유효). 단 "미래 신호" 차원은 재정의 필요(구성 FC가 서로 무관).
5. **Kakao POI 보조 관측**: `rect` 격자 POI는 이 outcome 패널의 FC가 아니며, 성공·폐업 outcome으로 검증되지 않았다. 완결 manifest가 있더라도 후보 250m·500m 카테고리 관측을 RAG 상세 맥락으로만 표시하고, FC·정렬·`fit_tier` 근거로 승격하지 않는다.
6. **FC-42 업종 검색 관심도 현재값**: 최신월·최근 3개월 원계열 관심도와 계절 국면은 현재 시기의 시장 관심 맥락으로만 표시한다. 계절 보정 `robust_slope12`와 단일 급등은 후보 가점·등급·정렬에 사용하지 않으며, `surge_active`는 `미검증 급등`으로 표시한다.

## 10. 미검증 / 후속

- **매출·손익·브랜드 outcome** — 이게 없으면 "좋은 입지" 최종 검증 불가. 인허가 생존은 상한 포화·행정 지연.
- churn_ratio 표본 2,108셀(opens≥5) — 소규모 셀 노이즈. 더 긴 창(2019~) or 상권 단위 pooling으로 재확인 여지.
