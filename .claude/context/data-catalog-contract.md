# 데이터 카탈로그 계약

## 분류 상태

- `core`: 후보 생성과 근거 설명에 기본 사용
- `conditional`: 특정 조건 또는 보조 설명에서만 사용
- `audit-only`: 운영 추천에서는 제외하고 분석·회귀 검증에만 사용
- `exclude`: 현재 추천 목적에 투입하지 않음
- `removed`: 용량 절감을 위해 원본 또는 파생 파일을 삭제함
- `missing`: 필요한 데이터가 저장소에 없음
- `reference`: 데이터가 아니라 매핑·정의용 사전(온톨로지·코드표)

`exclude`는 자동 삭제를 뜻하지 않는다. 삭제는 별도 사용자 승인 없이는 수행하지 않는다.

## 시간 사용 규칙

- 진짜 분기 시계열: 유동인구, 추정매출, 점포, 임대료, 상권변화지표 원천값과 라벨, 외국인생활인구, 인허가 패널
- 계단식 스냅샷: 상주인구, 직장인구, 버스정류소, 도시철도역사(개통 스냅샷), 도시철도망계획, **공동주택(K-apt 주1회)**
- 매 실행 시 최신 분기와 데이터별 관측 종료 시점을 다시 계산한다.
- 계단식 스냅샷의 최신 행에 최신 분기 코드가 있어도 실제 갱신 시점을 확인한다. 스냅샷 데이터로 분기 증감·모멘텀 계산 금지.

## 결합 규칙

- 기본 키: `기준_년분기_코드 + 공간단위 코드 + 서비스_업종_코드`.
- 업종이 없는 데이터는 같은 공간·분기의 배경값으로만 결합한다.
- 결합 전후 행 수와 키 중복률을 기록한다.
- many-to-many가 생기면 중단하고 교차표 또는 공간 중첩 규칙을 명시한다.
- 누락은 0으로 자동 대체하지 않는다. `null`과 `missing_reason`을 유지한다.
