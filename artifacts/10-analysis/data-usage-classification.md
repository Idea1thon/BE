# 추천 목적별 데이터 분류와 불필요 데이터 목록

## 결론

운영 제외 항목 중 용량 절감 효과가 있는 원자료와 파생물은 2026-08-31 삭제했다. 삭제하지 않은 제외 컬럼은 운영 allowlist로 통제한다.

2026-09-02 카카오 POI seed를 부분 이식했다. 이는 후보 공간을 넓히는 **조건부 seed 데이터**이지 매출·공실·성공 outcome 피처가 아니다. 같은 날 프로젝트 생성 격자 맥락도 확인했으나, 이는 **개별 상가 데이터셋이 아닌 합성 좌표 기반 보조 맥락**이다. 점포·추정매출은 여전히 결합 전 정규화가 선행되어야 `core`로 실사용 가능하다. 결합 규칙은 `data-integrity-check.md`와 `generated-gridpoint-seed-audit.md` 참조.

| 상주인구 | 주거·가족·배달·생활밀착 업종 조건 | 최신 유효 스냅샷 수준과 구성 | 분기 성장률 제외 |
| 직장인구 | 점심·오피스·주중 중심 조건 | 최신 유효 스냅샷 수준과 구성 | 분기 성장률 제외 |

| 임대료·공실률 | 권역 비용과 공급 위험 비교 | 임대료·공실률 분위, 기준 분기 | 매칭 없으면 누락 표시 |

## 3. 현재 운영 추천에 불필요하거나 제외할 데이터

| 항목 | 분류 | 제외 이유 | 보관 이유 |
| --- | --- | --- | --- |
| 모든 `.DS_Store` | 완전 제외 | 운영체제 메타데이터이며 분석 값이 없음 | 읽기 전용 `.git/.DS_Store`를 제외하고 삭제 완료 |
| 임대료 파일의 투자수익률 컬럼 | 운영 제외 | 점포 운영 입지보다 부동산 투자 성과 지표에 가까움 | 원본 보존·추후 투자자 기능 가능 |
| 로컬 브랜드 상권 지정 여부 | 삭제 완료 | 정적 정책 목록이며 현재 수요·최근 인기의 직접 근거가 아님 | 감사 결론만 문서에 보존 |
| 공동주택 low/none 지오코딩 행·소형 주거 누락분 | seed 제외·결측 표시 | 좌표 신뢰도가 없거나 K-apt 모집단 밖이라 위치를 확정할 수 없음 | 정밀 아파트 경계·소형 빌라 소스 확보 시 재검토 |
| 상주인구 분기 증감률 | 피처 제외 | 2023Q4 이후 장기간 동일값인 계단식 데이터 | 최신 수준은 보조 지표로 유효 |
| 직장인구 분기 증감률 | 피처 제외 | 연 1회 갱신·최근 반복값으로 분기 모멘텀 근거가 없음 | 최신 수준은 오피스 수요 보조 |
| 아파트 분기 증감률 | 피처 제외 | 계단식 갱신이라 분기 추세 왜곡 | 최신 주거 배경은 조건부 사용 |
| 상권변화지표 연속 gap 값 | 주력 피처 제외 | 업종별 개·폐업과 선형 상관이 약함 | LL/LH/HL/HH 산출 근거와 감사용 |
| 상권·배후지·행정동의 동일 지표 동시 투입 | 중복 제외 | 같은 현상을 세 번 가산해 공간 규모와 중첩을 과대 반영 | 각 단위는 역할별로 따로 보존 |
| 생성 격자 metrics를 개별 상가·매물로 표현 | 운영 제외 | 합성 좌표에 반경 집계한 공개 데이터이며 실제 점포·공실·주소·월세가 없음 | 생성 규칙·한계·감사 결과 보존 |
| 기존 A형 Top-K 점수·순위 | 결과 삭제 완료 | 점수와 과거매출 상관 0.9995로 신규 입지 성공 근거가 아님 | 보고서 수치와 결함 주입 회귀 규칙만 보존 |
| 기존 B형 Top-K 점수·고정 가중치 | 결과 삭제 완료 | 평균 F1 약 0.306, 업종별 부호 불안정, greenfield 제외 | 코드·보고서로만 감사 가능 |
| `output/`의 중간 상관·그림 파일 | 서비스 입력 제외 | 원자료가 아니라 분석 산출물이며 중복·누수 위험 | 보고서 재현과 발표 자료 |
| zip·PDF·발표 문서 | 서비스 입력 제외 | 모델 피처가 아닌 사람이 읽는 자료 | 공모전 문서와 감사 추적 |

## 4. 데이터는 유지하되 잘못된 값 사용을 금지

| 잘못된 사용 | 올바른 대체 |
| --- | --- |
| 유동·상주·직장인구 총량을 더해 인구 비율 생성 | 서로 다른 모집단임을 표시하고 각 데이터 내부 구성비 또는 표준화 수준으로 비교 |
| 동종 점포수만으로 경쟁이 나쁘다고 판정 | 점포수, 점포당 매출, 개·폐업, 시장 규모를 함께 제시 |
| 매출 상위 분위로 신규점포 성공 주장 | 현재 수요 근거로만 사용하고 진입·비용·반대 근거를 분리 |
| 권역 공실률로 특정 상가가 비었다고 표현 | 권역 공급 위험으로만 표현, 실제 매물 데이터 요구 |
| 상권변화지표를 업종별 리스크로 사용 | 업종 공통 지역 배경 리스크로 표시 |

## 5. 즉시 추가해야 하는 데이터

1. 개별 매물: 화면 요구를 구현하려면 최우선이다.
2. 외국인 방문·생활인구: 외국인 비율 지표를 실제 관측으로 만들기 위해 필요하다.
3. 신규점포 생존·성과 outcome: 향후 학습모델을 정당화하는 핵심 라벨이다.
4. 공식 개발·랜드마크 사건: 미래가치의 날짜·상태·출처를 만들기 위해 필요하다.
5. SNS·검색·뉴스: 합법적 API 또는 출처가 있는 집계값을 우선하고, 합성 JSON은 데모 전용으로 구분한다.
6. 상가·근생 POI: 카카오 로컬 API 샘플은 확보했으나, 선택 지역별 배치 수집과 `SeedSpatialBuilder` 연결 전까지는 **부분 이식·조건부**로 둔다.

## 삭제 기록

- 삭제 완료: 중복 데이터·소스코드 ZIP 약 350MB
- 삭제 완료: 아파트 원자료 약 7.6MB
- 삭제 완료: 로컬브랜드 원자료·파생 그래프/CSV 약 1.6MB + 관련 스크립트 5개(2026-09-01, 실행 불가)
- 삭제 완료: 기존 Top-K 결과·그래프 약 0.7MB
- 삭제 완료: 읽기 가능한 `.DS_Store`
- 유지: 임대료·공실률·수익률 혼합 CSV. 44KB뿐이고 임대료·공실률은 필요하므로 수익률 컬럼만 운영 allowlist에서 제외한다.
