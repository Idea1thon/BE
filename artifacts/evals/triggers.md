# Trigger 검증 세트

## Should trigger

1. 서울 송파구에서 커피숍 후보를 데이터 근거로 추천해줘.
2. 잠실동 입지 후보의 반대 근거까지 RAG 카드로 만들어줘.
3. 상권 데이터 중 추천에 불필요한 데이터만 다시 분류해줘.
4. 외국인 데이터를 추가했으니 영향 단계만 업데이트해줘.
5. 기존 입지 추천 결과를 최신 분기로 보완해줘.
6. 월세 300만원, 20평, 주차 조건을 입력 계약으로 바꿔줘.
7. 추천 후보 등급 기준을 검토해줘.
8. 기존 Top-K 모델이 운영에 안전한지 감사해줘.
9. 추천 Evidence JSON의 출처와 최신성을 QA해줘.
10. 강남구의 제과점 후보 생성 단계만 다시 실행해줘.

## Should not trigger

1. 완성된 입지 추천 보고서의 맞춤법만 고쳐줘.
2. 서울 상권분석서비스가 무엇인지 한 문단으로 설명해줘.
3. 이 CSV를 UTF-8로 변환만 해줘.
4. 상권 지도 PNG의 크기만 줄여줘.
5. Top-K 알고리즘의 일반적인 정의를 설명해줘.
6. 부동산 매물 사이트의 CSS 버튼을 수정해줘.
7. 추천 프롬프트 문장만 자연스럽게 다듬어줘.
8. 기존 그래프를 PPT에 붙여줘.
9. 송파구 행정동 목록만 출력해줘.
10. 상권 분석 코드의 문법 오류 한 줄만 고쳐줘.
