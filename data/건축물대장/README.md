# 건축물대장(GIS건물통합정보 파생) — 상업용 건물 단위

개별 상가 매물 데이터(월세·보증금·권리금·공실·호실·주차)가 저장소에 없고
민간 제휴/크롤링 전까지 확보 불가한 상황에서, **실재하는 상업용 건물 모집단**을
공개 데이터로 확보해 격자 합성좌표(`output/generated_evidence/`, 367개)를
대체하기 위한 이식이다.

## 한계 — 이 데이터로 하면 안 되는 것

- **매물이 아니다.** 건물이 상업 용도라는 사실이지 임대 가능 호실·공실·월세·권리금이 아니다.
- **건물 주용도 기준.** 주상복합(주용도=공동주택/업무시설)의 저층 상가는 누락된다.
- **GIS건물통합정보는 집합건물(구분상가)을 구분하지 않는다.** 건물당 footprint 1개,
  전유부 호실 없음. 호실·층별 용도·주차대수는 Tier 2 필요.
- footprint 중심좌표이며 정확한 도로명주소 호수·출입구 위치가 아니다.
