# 데이터 재고

## 요약

현재 저장소는 상권 단위의 수요·점포·매출·공간 데이터와 아파트·역 앵커를 보유하고, 카카오 POI는 잠실역 샘플까지 부분 이식했다. `scripts/recommendation_pipeline.py`가 이 데이터를 지점 후보와 RAG 근거로 묶는 MVP까지 구현되어 있다. 개별 매물·공실·공식 개발 사건의 상세성이 없으므로, POI와 프로젝트 생성 격자 맥락을 상세 점포나 성공 outcome으로 해석하지 않는다.

2026-09-01 실측 정합성 검사 완료: 상세 결과·판정·결합 규칙은 `data-integrity-check.md`, 재실행 스크립트는 `scripts/audit_data_integrity.py`, 원자료는 `output/data_integrity_report.json`.

2026-09-03 API·외부 출처 통합 감사: 키 상태·실호출/스냅샷·추천 사용 경계와 도로명주소 좌표제공 API 보류 사유는 [`artifacts/handoff_data_sources.md`](../handoff_data_sources.md)에 기록했다. 실제 키 값은 기록하지 않는다.

2026-09-03 데이터 스키마 계약: 원천·정규화·후보 Evidence의 3계층, 실제 컬럼 매핑, grain·기간·결합 키·결측·proxy 규칙은 [`data-schema.md`](data-schema.md)와 [`data-schema.json`](data-schema.json)에 기록했다. 작성 주체는 GPT(Codex)다.

## 품질 근거 (2026-09-01 갱신)

- 분기 시계열(20211~20261 실측): 점포, 추정매출, 길단위인구, 상권변화지표. 계단식(분기코드는 있으나 값은 연 1~2회): 상주인구, 직장인구 — 상권별 21분기 distinct 2~6개로 재확인.
- 임대료·공실률은 2021Q1~2025Q4 (권역 grain). 최신 시계열보다 1분기 뒤처짐.
- 단일 파일 시계열(길단위·상주·직장·상권변화)은 (분기+공간) 키 중복 0, 키 null 0.
- 공간 커버리지: 점포·길단위인구·상권변화지표는 영역-상권 1,650과 100% 일치. 추정매출 1,577, 상주 1,637, 직장 1,643 (부족분은 null 유지, 0 대체 금지). orphan 코드 0.
- 결합 위험은 전부 연도 분할 파일 병합·연도별 스키마 드리프트에 집중(H1~H4). `data-integrity-check.md`의 결합 규칙 7개 참조.
- 상권변화지표는 업종 컬럼이 없고 상권배후지 버전이 없다. 배후지 요청 시 상권값 fallback + grain 표시.
- 격자 합성 후보 seed는 공개 음식점 인허가·교통·아파트를 100m 합성 좌표에 집계한 보조 seed다. 25구 250점은 공식 행정동 425개 중 224개만 실제 레코드가 있다. 10개 외식 업종별 인허가 수를 전부 기록하고 `generator.params.industries`에 범위를 명시한다. **개별 상가·매물 데이터가 아니며**, `synthetic_anchor` 후보는 추천 상한이 조건부다(`generated-gridpoint-seed-audit.md`).
- 인코딩 혼재: 대부분 CP949, 임대료 UTF-8-BOM, 추정매출 2024 배후지 UTF-8.
